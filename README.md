# In the Earth and Stars

**Poetry by Andrew Milligan**

*Poems about everything that doesn't quite make sense.*

Welcome. This repository contains the source files for **In the Earth and Stars**, a small independent poetry website exploring the everyday, the absurd, memory, loss, people, and our peculiar place in the universe.

**[Visit the poetry website](https://andemilligan-oss.github.io/in-the-earth-and-stars/)**

## Where to begin

If you're new here, **[Start Here](https://andemilligan-oss.github.io/in-the-earth-and-stars/start-here/)** offers six selected poems as an introduction.

You can also:

## About this repository

The site is built from static HTML and CSS and hosted using GitHub Pages. The repository is public so its source files and revision history can be viewed. **The website above is the intended reading experience**; you don't need to know anything about GitHub or programming to enjoy the poems.

The repository is maintained as the home of the published website, rather than as an open collaborative writing project.
